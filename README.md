
# java-lotto-precourse
### 요구사항
- **else 사용 x**
- 함수, 메소드의 길이는 **15라인 이하**
- **SRP 준수**
- **ENUM 적용**
- UI 로직을 제외한 기능에 대한 **단위테스트 수행**

### 입력
#### 구입 금액
- 로또 1장은 1,000원
- 1,000원 단위로 입력, 1,000원으로 나누어 떨어지지 않을 경우 예외 처리
#### 당첨 번호 입력
- 6개 입력, 쉼표를 기준으로 구분
- 6개 초과할 경우 예외 처리
- 중복된 번호가 존재할 경우 예외 처리
- 1~45 사이의 숫자가 아닐 경우 예외 처리
#### 보너스 번호 입력
- 1개 입력
- 미리 입력된 당첨 번호와 중복될 경우 예외 처리
- 1~45 사이의 숫자가 아닐 경우 예외 처리

### 로또 생성기
- 1~45 사이의 중복되지 않는 숫자 6개

### 당첨 검증
- 입력한 값과 몇 개 일치하는 지 판단

### 당첨 결과별 등수와 금액	
- enum 활용
- 1등: 번호 6개 일치, 2,000,000,000원
- 2등: 번호 5개 + 보너스 번호 일치, 30,000,000원
- 3등: 번호 5개 일치, 1,500,000원
- 4등: 번호 4개 일치, 50,000원
- 5등: 번호 3개 일치, 5,000원

### 수익률 계산
#### 수익 합
- 당첨 금액의 합
#### 수익률
- 로또 구입 금액과 계산
- 소수점 둘째 자리에서 반올림

### 출력
#### 발행한 로또 수량 및 번호 출력
- 로또 번호는 오름차순 정렬
#### 당첨 내역 출력
>
> 당첨 통계
>
> \---
>
> 3개 일치 (5,000원) - n개
>
> 4개 일치 (50,000원) - n개
>
> 5개 일치 (1,500,000원) - n개
>
> 5개 일치, 보너스 볼 일치 (30,000,000원) - n개
>
> 6개 일치 (2,000,000,000원) - n개
>
>  총 수익률은 n%입니다.
